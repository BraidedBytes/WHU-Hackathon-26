# Spoilsport repository audit — 2026-09-28

## Verified

- `npm ci` installs the locked dependencies; `npm run lint`, `npm run build`, and `node --test extension/test/*.test.mjs` pass.
- `npm audit --audit-level=moderate` reports zero known vulnerabilities.
- The Chrome extension ZIP contains only runtime files, with no API key or local config file. `.env.local` and `extension/config.js` are Git ignored.
- In a disposable Chrome profile against the local app, the demo button loads two protected films without TMDB credentials and the extension acknowledges both.
- The first paint masks candidate text. With no OpenAI credentials, suspects remain blurred and show `unchecked`; unrelated text stays readable. Late comments are also masked.
- Keyword mode, popup film count, watched-film sync, dynamic `data-spoilsport-ignore`, and navigation back to the app pass the browser smoke check.
- The extension API rejects foreign browser origins and non-JSON requests. The app binds to `127.0.0.1` for local runs.

## Changes from the audit

- Replaced the removed `next lint` command with the ESLint CLI and fixed lint errors.
- Made demo films self-contained so the judge path works before TMDB credentials are available.
- Kept ambiguous, low-confidence spoiler verdicts blurred and triggered term expansion when a film enters the watchlist.
- Delayed DOM annotations on the demo forum until React hydrates while retaining the first-paint CSS mask.
- Updated the extension coordination brief to describe the server-side OpenAI proxy instead of an extension-bundled key.

## Pending live checks

The local checkout had no `.env.local` at audit time. Live TMDB search, OpenAI chat, AI safe/spoiler classification, classifier fixture accuracy, and the Wikipedia plot/cast acceptance check therefore remain unverified. Add `TMDB_READ_TOKEN`, `OPENAI_API_KEY`, and `OPENAI_MODEL` to the Git-ignored `.env.local`, restart the local server, then run:

```bash
node extension/scripts/eval.mjs
SPOILSPORT_LIVE_APP=1 node extension/scripts/smoke.mjs
```

The offline smoke check can be repeated with:

```bash
SPOILSPORT_LIVE_APP=1 SPOILSPORT_OFFLINE=1 node extension/scripts/smoke.mjs
```
